# Щи и Борщи · Персонал (Android)

Приложение для сотрудников кафе. Внутри — страница https://shchiiborshchi.ru/staff/.
Отдельно работает служба, которая раз в 5 секунд проверяет новые заявки (даже при выключенном экране)
и играет мелодию как будильник, пока заявку не примут.

Сборка — автоматически на GitHub Actions при каждом изменении в ветке main.
Готовый файл: вкладка **Releases** → `shchi-staff.apk`.
